One-line install

Picks the right build for this machine, verifies it against the release SHA256SUMS, and installs opencrabs and rtk. Add --dry-run to see the plan without installing.

Linux and macOS, into /usr/local/bin or ~/.local/bin when that is not writable:

curl -fsSL https://opencrabs.com/install.sh | bash

Windows, into %LOCALAPPDATA%\OpenCrabs\bin, added to your user PATH:

iwr -useb https://opencrabs.com/install.ps1 | iex

Then run opencrabs. Both scripts accept a pinned release and a custom directory: --version v0.5.11 and --dir on Linux and macOS, -Version and -Dir on Windows.

Requirements

The binary is self-contained, but it links a few system libraries. Install these first or the first run fails with a missing-library error.

Linux
  • OpenMP and OpenSSL: sudo apt update && sudo apt install -y libgomp1 libssl3 on Debian and Ubuntu. On Fedora and RHEL: sudo dnf install -y libgomp openssl-libs.
  • glibc 2.38 or newer, which means Ubuntu 24.04+, Debian 13+ or Fedora 39+. Ubuntu 22.04 and Debian 12 are too old for this build.
macOS
  • macOS 11.0 or newer. No extra libraries, everything it needs ships with the system.
  • The app is not notarized, so Gatekeeper blocks the first launch. Allow it in System Settings > Privacy & Security (click Open Anyway), or clear the flag on the real binary, which lives inside the bundle: xattr -d com.apple.quarantine ~/Applications/OpenCrabs.app/Contents/MacOS/opencrabs
Windows
  • Microsoft Visual C++ 2015-2022 Redistributable, x64 build. Windows 10 and 11 usually ship it already.

After download

tar xzf opencrabs-<tag>-<platform>.tar.gz sudo install -m 755 opencrabs rtk /usr/local/bin/ opencrabs

On macOS the archive holds an app bundle, so the second step moves OpenCrabs.app into ~/Applications and links the CLI instead.
