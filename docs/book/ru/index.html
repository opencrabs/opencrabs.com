OpenCrabs

Introduction

OpenCrabs: автономный агент оркестрации ИИ, не привязанный к провайдеру, работающий как единый бинарный файл на Rust. Он автоматизирует ваш терминал, браузер, channels (Telegram/Discord/Slack/WhatsApp/Trello) и кодовую базу, уважая вашу приватность и оставляя контроль у вас.

11,091 тестов по providers, инструментам, channels, TUI, self-healing и автоматизации browser.

Что отличает OpenCrabs

Ноль телеметрии: даже опции включения нет

  • OpenCrabs никогда не связывается с «домашним сервером». Никогда. Никакой аналитики, никакого трекинга, никакой статистики использования, никакого удалённого логирования, никаких отчётов о сбоях
  • Ваши переписки, инструменты, память, конфигурация и API-ключи никогда не покидают вашу машину
  • Единственный исходящий трафик: тот, который вы инициируете сами: вызовы LLM API, веб-поиск, команды GitHub, автоматизация браузера
  • Это не галочка в политике приватности: нет кода телеметрии, который нужно отключать, нет флага отказа, нет аналитического сервиса, который нужно блокировать. Просто нечего отправлять

Независимость от провайдера заложена в дизайн

  • 16 встроенных провайдеров + Custom OpenAI Compatible: Anthropic Claude, OpenAI, Gemini, Xiaomi MiMo, OpenRouter, Qwen (DashScope), MiniMax, Ollama, z.ai GLM, GitHub Copilot, Codex, Codex CLI, OpenCode, OpenCode CLI, Moonshot AI (Kimi), Command Code CLI
  • Нативная интеграция CLI: используйте Claude Code CLI, OpenCode CLI, Codex CLI и Command Code CLI как провайдеров без API-кл��чей
  • Липкая цепочка fallback: автоматическое переключение при лимитах запросов или ошибках, данные о здоровье провайдеров переживают перезапуски
  • Кэширование промптов в Anthropic, OpenRouter, Gemini, Qwen DashScope снижает расходы до 95%
  • Переопределение окна контекста: ограничьте или расширьте контекст любой модели через конфигурацию (встроенный provider OpenCrabs это исключение: его окно зафиксировано на 200k)

  • Moonshot AI (Kimi): эндпоинты API plan (api.moonshot.ai) и Coding plan (api.kimi.com), настройка reasoning-effort, окно контекста по тарифному плану

Multi-Agent Orchestration

  • Sessions (полностью изолированные агенты) у каждой свой brain, провайдер, модель, рабочая директория и история
  • Типизированные суб-агенты: general, explore, plan, code, research с настроенным доступом к инструментам
  • Оркестрация команд: team_create, team_broadcast, team_delete для согласованных рабочих процессов
  • Переопределение провайдера/модели на каждый вызов - миксуйте модели между командами (план на GLM, код на Deepseek, ревью на Kimi)
  • Протокол A2A: шлюз JSON-RPC 2.0 для связи агентов между собой

Нативная коммуникация через channels

  • Telegram, Discord, Slack, WhatsApp, Trello - полная интеграция ботов с личными сообщениями, группами и тредами

  • Изоляция session по темам форума: каждая тема в супер-группах Telegram получает собственную session
  • Реакции Telegram: бот читает входящие эмодзи-реакции и может ответить реакцией вместо сообщения, когда это уместно

  • Реакции посреди хода (v0.3.61): реакция во время выполняющегося хода внедряется в текущий цикл вместо запуска второго хода
  • Подсказки продолжения (v0.3.69) (необязательные follow-up-кнопки в Telegram, Discord, Slack, WhatsApp; в TUI) заполнение без отправки
  • Повторное закрепление карточки плана в Telegram (v0.3.71) - карточка плана заново закрепляется и вбирает текст, когда её засыпало сообщениями
  • Полный захват истории групп (v0.3.73): в историю сохраняется каждое сообщение группы, даже от отправителей и ботов не из allowlist
  • Корректный собеседник в группах (v0.3.73): отправитель из истории группы больше не принимается за текущего собеседника
  • Наследование session: /new наследует рабочую директорию вашей последней session
  • /goal во всех channels: ставьте автономные цели из Telegram, Discord, Slack, WhatsApp
  • Голосовая поддержка: локальные Whisper STT + Piper TTS, полностью офлайн
  • Восстановление после сбоя между channels: ожидающие запросы возвращаются в исходный channel после перезапуска
  • /cowork: создавайте общие рабочие пространства из channels и TUI
  • /rename, /profiles, /cd - управляйте sessions, профилями и директориями из любого channel

Быстрый старт

# Install (Linux/macOS)
ARCH=$(uname -m | sed 's/x86_64/amd64/;s/aarch64/arm64/')
OS=$(uname -s | tr A-Z a-z)
TAG=$(command -v jq >/dev/null 2>&1 && curl -s https://api.github.com/repos/opencrabs/opencrabs/releases/latest | jq -r .tag_name || curl -s https://api.github.com/repos/opencrabs/opencrabs/releases/latest | grep -o '"tag_name":"[^"]*"' | cut -d'"' -f4)
curl -fsSL "https://github.com/opencrabs/opencrabs/releases/download/${TAG}/opencrabs-${TAG}-${OS}-${ARCH}.tar.gz" | tar xz
./opencrabs

# Or via Cargo (requires Rust 1.94+)
cargo install opencrabs --locked

Автообновление включено по умолчанию. Отключите через [agent] auto_update = false в ~/.opencrabs/config.toml.
