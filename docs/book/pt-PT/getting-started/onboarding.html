OpenCrabs

Onboarding

A first run does not open the wizard. OpenCrabs goes straight to the chat, with its built-in provider already provisioned and the agent greeting you. The onboarding wizard is opt-in: run opencrabs --onboard, or /onboard from inside a session.

Os vídeos com demonstrações estão na página Vídeos de Onboarding.

O caminho rápido permite-te conversar com o agente em menos de 3 minutos.

9. Sobre o agenteEscreve algo sobre a personalidade do agente. Prime Enter

Fluxo de onboarding

O assistente é uma TUI controlada pelo teclado, com 8 passos. Navega com as setas, usa Tab para avançar e Esc para voltar atrás.

PassoEcrãO que fazes
1Seleção de modoEscolhe QuickStart (sem channels) ou Advanced
2Espaço de trabalhoEscolhe uma pasta de trabalho para as operações com ficheiros
3Provider e autenticaçãoEscolhe o provider → cola a chave de API → escolhe o modelo (obtido em tempo real)
4ChannelsSpace para ativar ou desativar channels → Enter em cada um para configurar
5VozProvider de STT (Groq, Whisper local ou desativado) + voz de TTS
6ImagemInterruptor de visão + modelo de geração + chave de API
7DaemonInstala o daemon em segundo plano (opcional)
8Configuração do brainGera automaticamente o SOUL.md a partir do teu perfil

Configuração de channels (passo 4)

O ecrã de channels lista 5 integrações: Telegram, Discord, WhatsApp, Slack e Trello.

  • Space ativa ou desativa um channel
  • Enter num channel ativado abre o respetivo ecrã de configuração (token, IDs, listas de permissões)
  • Enter em Continue ou Tab avança para o passo seguinte
  • Cada ecrã de configuração de channel tem um botão Test Connection

Consulta Channels Overview para o guia completo de navegação.

Voltar a executar a configuração

Podes saltar para qualquer passo sem voltar a executar o assistente completo:

ComandoPasso

/onboard:providerSeleção de provider e modelo
/onboard:channelsSeletor de channels
/onboard:voiceConfiguração de voz
/onboard:imageConfiguração de imagem

Depois do onboarding, o agente arranca e apresenta-se. Lê os seus ficheiros brain (SOUL.md, AGENTS.md, TOOLS.md) e começa uma conversa.

Bootstrap

Na primeira execução, o agente passa por uma fase de bootstrap:

  • Fica a conhecer-te (nome, preferências, forma de trabalhar)
  • Define a sua identidade (nome, personalidade, emoji)
  • Abre o SOUL.md contigo para discutir valores
  • Configura o USER.md com o teu perfil

O ficheiro de bootstrap (BOOTSTRAP.md) apaga-se quando termina.

Migrar a partir de outra ferramenta

Já usas ClaudeCode, OpenClaw, Hermes ou outro harness de agente de IA? O teu agente pode migrar os teus dados existentes (memória, skills, comandos personalizados, preferências) para os seus próprios ficheiros brain, em linguagem natural. Não é preciso mover ficheiros manualmente.

Funciona com qualquer agente ou harness de programação que guarde a configuração localmente. A migração procura no teu sistema de ficheiros as pastas de configuração da outra ferramenta, lê o conteúdo e converte-o para o formato de ficheiros brain do OpenCrabs (SOUL.md, USER.md, TOOLS.md, MEMORY.md, AGENTS.md, CODE.md).

Migração guiada

Se quiseres rever o que é migrado antes de a migração acontecer:

Procura localmente os meus dados do ClaudeCode/OpenClaw/Hermes (ou de qualquer outro harness de agente que eu usasse), faz uma auditoria de uma migração para os nossos próprios ficheiros brain, informa-me quando terminares e executa só quando eu confirmar e aprovar.

O agente vai:

  1. Procurar no teu sistema de ficheiros as pastas de configuração da outra ferramenta
  2. Ler e analisar todos os ficheiros relevantes (memória, comandos, skills, preferências)
  3. Produzir uma auditoria que mostra exatamente o que vai para onde
  4. Esperar pela tua confirmação
  5. Executar a migração e apresentar um resumo completo

Migração autónoma

Se só queres que fique feito:

Procura localmente os meus dados existentes de agentes ou harness e migra tudo para os nossos próprios ficheiros brain, sem precisar da minha aprovação. Avança, planeia e executa, e informa-me quando terminares, com um resumo completo.

O agente salta a etapa de auditoria, planeia a migração internamente, executa-a e dá-te um resumo de tudo o que foi movido.

O que é mapeado

OrigemDestinoExemplo
Memória / CLAUDE.md / ficheiros de contextoMEMORY.mdDecisões do projeto, contexto anterior

Dica: Executa a migração logo a seguir ao onboarding, enquanto o contexto está fresco. O agente já tem o teu USER.md e o SOUL.md do assistente, por isso pode fazer a fusão de forma inteligente em vez de substituir.

Pasta de trabalho

O agente opera dentro de uma pasta de trabalho para as operações com ficheiros. Muda-a com:

  • Comando /cd no chat
  • Seletor de pastas na TUI (Tab para selecionar)
  • Ferramenta config_manager set_working_directory

A pasta de trabalho é guardada por session. Ao mudar de session, a pasta é restaurada automaticamente.

Dica de filtro de modelos (v0.3.78)

O seletor de modelos do onboarding passa agora a mostrar sempre uma dica de filtro acima da lista de modelos (“Type to filter…”). Antes, a dica só aparecia depois de começares a escrever, por isso os utilizadores não sabiam que existia filtragem. Além disso, um ID de modelo escrito exatamente tem agora prioridade sobre uma correspondência parcial: se escreveres claude-opus-4-8 exatamente, seleciona esse modelo, mesmo que outros modelos contenham a mesma sequência de caracteres.
