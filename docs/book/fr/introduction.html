OpenCrabs

Introduction

OpenCrabs est un agent d’orchestration IA auto-hébergé et agnostique du provider qui s’exécute comme un unique binaire Rust. Il automatise votre terminal, votre navigateur, vos channels (Telegram/Discord/Slack/WhatsApp/Trello) et votre codebase, tout en respectant votre vie privée et en vous gardant aux commandes.

11,422 tests sur les providers, les outils, les channels, le TUI, le self-healing et l’automatisation de browser.

Ce qui distingue OpenCrabs

Zéro télémétrie, même pas en opt-in

  • OpenCrabs ne téléphone jamais à la maison. Jamais. Pas d’analytics, pas de tracking, pas de statistiques d’utilisation, pas de logs distants, pas de rapports de plantage
  • Vos conversations, outils, mémoire, configuration et clés API ne quittent jamais votre machine
  • Le seul trafic sortant est celui que vous initiez explicitement : appels d’API LLM, recherches web, commandes GitHub, automatisation du navigateur
  • Pas une case de politique de confidentialité : il n’y a aucun code de télémétrie à désactiver, aucun flag d’opt-out, aucun service d’analytics à bloquer. Il n’y a simplement rien à envoyer

Agnostique du provider par conception

  • 18 fournisseurs intégrés + Custom compatible OpenAI : OpenCrabs (intégré, gratuit), Anthropic Claude, OpenAI, Gemini, Xiaomi MiMo, OpenRouter, Qwen (DashScope), DeepSeek, Z.ai, MiniMax, Moonshot Kimi, Command Code CLI, Ollama, vLLM, LM Studio, llama.cpp et tout ce qui est compatible OpenAI.
  • Intégration CLI native: utilisez Claude Code CLI, OpenCode CLI, Codex CLI et Command Code CLI comme providers sans clés API
  • Chaîne de fallback persistante: failover automatique sur rate limits ou erreurs, persistance sensible à l’état de santé qui survit aux redémarrages
  • Prompt caching sur Anthropic, OpenRouter, Gemini et Qwen DashScope réduit les coûts jusqu’à 95 %
  • Override de la fenêtre de contexte: plafonnez ou étendez le contexte de n’importe quel model via la config (le provider OpenCrabs intégré est l’exception : sa fenêtre est fixée à 200k)
  • Xiaomi MiMo: plus de 30 models dont la série de reasoning MiMo, provider à clé
  • Moonshot AI (Kimi): endpoints du plan API (api.moonshot.ai) et du plan Coding (api.kimi.com), config de reasoning-effort, fenêtre de contexte selon le palier de plan

Multi-Agent Orchestration

  • Les sessions sont des agents totalement isolés, chacune avec son propre brain, provider, model, répertoire de travail et historique
  • Sous-agents typés : general, explore, plan, code, research avec un accès aux outils adapté
  • Orchestration d’équipes : team_create, team_broadcast, team_delete pour des workflows coordonnés
  • Overrides provider/model par appel: mélangez les models entre équipes (planifier avec GLM, coder avec Deepseek, relire avec Kimi)
  • Protocole A2A: passerelle JSON-RPC 2.0 pour la communication agent-à-agent

Découverte des directives de projet (v0.3.59)

OpenCrabs découvre automatiquement les fichiers de règles que d’autres outils de codage IA déposent dans un repo. Pointez l’agent sur n’importe quel dépôt (via /cd, un workspace de channel, ou en le lançant à l’intérieur) et il scanne les conventions livrées par Claude Code, Cursor, Windsurf, Cline, Gemini CLI, GitHub Copilot, OpenCode et le standard inter-outils AGENTS.md. Pas de config, pas d’étape d’import.

SourceFichiers
Standard inter-outilsAGENTS.md
Claude CodeCLAUDE.md, CLAUDE.local.md, .claude/CLAUDE.md, .claude/rules/**/*.md
Cursor.cursorrules, .cursor/rules/**/*.mdc
Windsurf.windsurfrules
Cline.clinerules (file or .clinerules/**/*.{md,txt})
Gemini CLIGEMINI.md
GitHub Copilot.github/copilot-instructions.md
OpenCode.opencode/AGENTS.md

L’index se reconstruit quand vous faites /cd vers un nouveau répertoire, donc les fichiers de directives sont toujours à jour.

Démarrage rapide

# Installer (Linux et macOS)
curl -fsSL https://opencrabs.com/install.sh | bash

# Ou via Cargo (nécessite Rust 1.94+)
cargo install opencrabs --locked

L’installeur résout la dernière version, vérifie le téléchargement avec le SHA256SUMS publié et laisse la commande opencrabs disponible. Sur macOS cette commande est un lien symbolique vers ~/Applications/OpenCrabs.app, donc ne cherchez pas un binaire isolé à côté de l’archive extraite. Toutes les options et les procédures manuelles par plateforme sont sur Installation.

Auto-update activé par défaut. Désactivez avec [agent] auto_update = false dans ~/.opencrabs/config.toml.
