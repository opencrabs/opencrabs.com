OpenCrabs

Onboarding

A first run does not open the wizard. OpenCrabs goes straight to the chat, with its built-in provider already provisioned and the agent greeting you. The onboarding wizard is opt-in: run opencrabs --onboard, or /onboard from inside a session.

Panduan video ada di halaman Video Onboarding.

Mulai Cepat (3 menit)

Jalur cepat ini membuat Anda bisa mengobrol dengan agent dalam waktu kurang dari 3 menit.

LangkahAksi
1. ModeTekan Enter pada QuickStart
2. WorkspaceTekan Enter untuk menerima jalur default
3. ProviderGunakan panah untuk memilih provider Anda (misalnya z.ai), lalu tekan Enter. Gunakan panah bawah untuk memilih paket (misalnya Coding), lalu tekan Enter
4. API KeyTempel kunci Anda (Cmd+V / Ctrl+V / Cmd+Shift+V / Ctrl+Shift+V), lalu tekan Enter. Daftar model dimuat langsung
5. ModelGunakan panah untuk memilih model Anda (misalnya gemini-2.5-pro), lalu tekan Enter
6. DaemonGunakan panah untuk memilih apakah dijalankan sebagai daemon latar belakang, lalu tekan Enter
7. Vibe CheckSemua pemeriksaan harus menampilkan ✅. Tekan Enter
8. Tentang AndaTulis sesuatu tentang diri Anda. Semakin banyak yang diketahui agent, semakin baik. Tekan Enter
9. Tentang AgentTulis sesuatu tentang kepribadian agent. Tekan Enter
10. ChatAnda sudah masuk. Mulai berbicara dengan agent Anda

Alur Onboarding

Wizard ini adalah TUI yang dikendalikan keyboard dengan 8 langkah. Navigasi dengan tombol panah, Tab untuk maju, Esc untuk kembali.

LangkahLayarYang Anda lakukan
1Pilih ModePilih QuickStart (lewati channel) atau Advanced
2WorkspacePilih direktori kerja untuk operasi file
3Provider & AutentikasiPilih provider → tempel API key → pilih model (diambil langsung)
4ChannelsSpace untuk mengaktifkan atau menonaktifkan channel → Enter pada tiap channel untuk mengatur
5SuaraProvider STT (Groq, Whisper lokal, atau nonaktif) + suara TTS
6ImagePengaktifan Vision + model pembuatan + API key
7DaemonPasang daemon latar belakang (opsional)
8Pengaturan BrainBuat SOUL.md secara otomatis dari profil Anda

Pengaturan Channel (Langkah 4)

Layar channel menampilkan 5 integrasi: Telegram, Discord, WhatsApp, Slack, Trello.

  • Space mengaktifkan atau menonaktifkan channel
  • Enter pada channel yang aktif membuka layar pengaturannya (token, ID, allowlist)
  • Enter pada Continue atau Tab melewati ke langkah berikutnya
  • Setiap layar pengaturan channel memiliki tombol Test Connection

Lihat Ringkasan Channels untuk panduan navigasi lengkap.

Setelah onboarding, agent Anda aktif dan memperkenalkan diri. Ia membaca file brain-nya (SOUL.md, AGENTS.md, TOOLS.md) dan memulai percakapan.

Bootstrap

Pada saat pertama kali dijalankan, agent melewati fase bootstrap:

  • Mengenal Anda (nama, preferensi, gaya kerja)
  • Menentukan identitasnya (nama, kepribadian, emoji)
  • Membuka SOUL.md bersama Anda untuk membahas nilai-nilai
  • Menyiapkan USER.md dengan profil Anda

File bootstrap (BOOTSTRAP.md) akan menghapus dirinya sendiri setelah selesai.

Migrasi dari Tool Lain

Sudah memakai ClaudeCode, OpenClaw, Hermes, atau harness agent AI lainnya? Agent Anda dapat memindahkan data yang sudah ada (memori, skill, perintah kustom, preferensi) ke file brain miliknya menggunakan bahasa alami. Tidak perlu memindahkan file secara manual.

Ini berfungsi dengan semua agent atau harness coding yang menyimpan konfigurasi secara lokal. Migrasi mencari direktori konfigurasi tool lain di filesystem Anda, membaca isinya, dan memetakannya ke format file brain OpenCrabs (SOUL.md, USER.md, TOOLS.md, MEMORY.md, AGENTS.md, CODE.md).

Migrasi Terpandu

Jika Anda ingin meninjau apa saja yang akan dimigrasi sebelum prosesnya berjalan:

Cari data ClaudeCode/OpenClaw/Hermes saya secara lokal (atau harness agent lain yang pernah saya pakai) dan audit migrasi ke file brain kita, laporkan setelah selesai, jalankan setelah saya konfirmasi dan setujui.

Agent akan:

  1. Mencari direktori konfigurasi tool lain di filesystem Anda
  2. Membaca dan mengurai semua file terkait (memori, perintah, skill, preferensi)
  3. Membuat audit yang menunjukkan secara tepat apa dipetakan ke mana
  4. Menunggu konfirmasi Anda
  5. Menjalankan migrasi dan melaporkan rincian lengkap

Migrasi Otomatis

Jika Anda ingin langsung selesai:

Cari data agent/harness saya yang sudah ada secara lokal dan migrasikan semuanya ke file brain kita, tanpa perlu persetujuan saya. Langsung rencanakan dan jalankan, lalu laporkan setelah selesai dengan rincian lengkap.

Agent melewati langkah audit, merencanakan migrasi secara internal, menjalankannya, dan memberi Anda ringkasan semua yang dipindahkan.

Direktori Kerja

Agent bekerja di dalam direktori kerja untuk operasi file. Ubah dengan:

  • Perintah /cd di chat
  • Pemilih direktori di TUI (Tab untuk memilih)
  • Tool config_manager set_working_directory

Direktori kerja disimpan per sesi. Saat berpindah sesi, direktori dipulihkan secara otomatis.

Petunjuk Filter Model (v0.3.78)

Pemilih model onboarding sekarang selalu menampilkan petunjuk filter di atas daftar model (“Type to filter…”). Sebelumnya, petunjuk ini hanya muncul setelah Anda mulai mengetik, sehingga pengguna tidak tahu bahwa filter tersedia. Selain itu, ID model yang diketik persis sekarang mengalahkan pencocokan substring: jika Anda mengetik claude-opus-4-8 secara persis, model tersebut dipilih meskipun model lain memiliki substring yang sama.
