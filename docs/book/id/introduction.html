OpenCrabs

Introduction

OpenCrabs adalah agen orkestrasi AI yang di-hosting sendiri dan tidak terikat provider, berjalan sebagai satu biner Rust. Ia mengotomatiskan terminal, browser, channels (Telegram/Discord/Slack/WhatsApp/Trello), dan codebase Anda, sambil menghormati privasi Anda dan menjaga kendali tetap di tangan Anda.

11,091 test mencakup provider, tools, channels, TUI, self-healing, dan otomatisasi browser.

Apa yang Membedakan OpenCrabs

Nol Telemetri, Bahkan Tanpa Opt-In

  • OpenCrabs tidak pernah menelepon pulang. Sesekali pun tidak. Tanpa analitik, tanpa pelacakan, tanpa statistik penggunaan, tanpa logging jarak jauh, tanpa laporan crash
  • Percakapan, tools, memori, konfigurasi, dan kunci API Anda tidak pernah meninggalkan mesin Anda
  • Satu-satunya trafik keluar adalah yang Anda mulai sendiri secara eksplisit: panggilan LLM API, pencarian web, perintah GitHub, otomasi browser
  • Ini bukan sekadar kotak centang kebijakan privasi: tidak ada kode telemetri untuk dinonaktifkan, tidak ada flag opt-out, tidak ada layanan analitik untuk diblokir. Memang tidak ada apa pun untuk dikirim

Bebas Provider Sejak Desain

  • 18 provider bawaan + Custom yang kompatibel OpenAI: OpenCrabs (bawaan, gratis), Anthropic Claude, OpenAI, Gemini, Xiaomi MiMo, OpenRouter, Qwen (DashScope), DeepSeek, Z.ai, MiniMax, Moonshot Kimi, Command Code CLI, Ollama, vLLM, LM Studio, llama.cpp, dan apa pun yang kompatibel OpenAI.
  • Integrasi CLI natif: gunakan Claude Code CLI, OpenCode CLI, Codex CLI, dan Command Code CLI sebagai provider tanpa kunci API
  • Rantai fallback lengket: failover otomatis saat rate limit atau error, persistensi sadar-kesehatan bertahan melewati restart
  • Prompt caching di Anthropic, OpenRouter, Gemini, Qwen DashScope memangkas biaya hingga 95%
  • Override jendela konteks: batasi atau perluas konteks model apa pun lewat konfigurasi (provider OpenCrabs bawaan adalah pengecualian: jendelanya tetap 200k)
  • Xiaomi MiMo: 30+ model termasuk seri reasoning MiMo, provider berkunci
  • Moonshot AI (Kimi): endpoint API plan (api.moonshot.ai) dan Coding plan (api.kimi.com), konfigurasi reasoning-effort, jendela konteks sesuai tier paket

Multi-Agent Orchestration

  • Sessions adalah agen yang terisolasi penuh, masing-masing dengan brain, provider, model, direktori kerja, dan riwayatnya sendiri
  • Sub-agent bertipe: general, explore, plan, code, research dengan akses tools yang disesuaikan
  • Orkestrasi tim: team_create, team_broadcast, team_delete untuk alur kerja terkoordinasi
  • Override provider/model per panggilan: campur model antar tim (plan dengan GLM, code dengan Deepseek, review dengan Kimi)
  • Protokol A2A: gateway JSON-RPC 2.0 untuk komunikasi antar agen

Penemuan Direktif Proyek (v0.3.59)

OpenCrabs otomatis menemukan file aturan yang ditinggalkan tools coding AI lain di sebuah repo. Arahkan agen ke repositori mana pun (lewat /cd, workspace channel, atau menjalankannya di dalamnya) dan ia memindai konvensi dari Claude Code, Cursor, Windsurf, Cline, Gemini CLI, GitHub Copilot, OpenCode, dan standar lintas-tool AGENTS.md. Tanpa konfigurasi, tanpa langkah impor.

Mulai Cepat

# Pasang (Linux dan macOS)
curl -fsSL https://opencrabs.com/install.sh | bash

# Or via Cargo (requires Rust 1.94+)
cargo install opencrabs --locked

Pemasang mengambil versi terbaru, memeriksa unduhan terhadap SHA256SUMS yang diterbitkan, dan meninggalkan perintah opencrabs yang bisa dipanggil. Di macOS perintah itu adalah symlink ke ~/Applications/OpenCrabs.app, jadi jangan mencari berkas biner lepas di samping arsip yang diekstrak. Semua flag dan cara manual per platform ada di Instalasi.

Pembaruan otomatis aktif secara default. Nonaktifkan dengan [agent] auto_update = false di ~/.opencrabs/config.toml.
